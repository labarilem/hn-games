# Local typefaces

Inter (variable, weights 100–900) is used for interface text. Barlow Condensed
(500, 600, 700) is used for display headings and the wordmark. The Latin WOFF2
subsets are served locally through `next/font/local`; neither page loads nor
production builds need a font provider connection.

Sources: [Inter](https://fonts.google.com/specimen/Inter) and
[Barlow Condensed](https://fonts.google.com/specimen/Barlow+Condensed), downloaded
from Google Fonts. Each family has its SIL Open Font License alongside the
font files. Other scripts use the system fallback fonts.
